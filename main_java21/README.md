#Introduction To HashSet

Definition:-
. A HashSet is a Collection that contains no duplicate elements and is backed by a hash table cusing a HashMap internally.
. It is part of the java.util.package.

Characteristics:-
No Duplicates:- Automatically Prevents Duplicates values.

UnOrdered:- The Elements are not Stored in any particular order.

Fast Operations:- Offers Constant-time performance (0(1)) for basic  operations like add, remove and contains an average.

Null Elements:- Allows one null Element.

Common Methods:- 
. add(element)'
  remove(element),
  contains(element),
  size(),
  isEmpty(),
  clear() and methods for iteration.

Use Cases:- 
. Eliminating duplicates from a collection.
. Fast membership checking.
. Implementing mathematical sets(union , intersection , difference).
