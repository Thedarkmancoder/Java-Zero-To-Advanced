#Queue

Definition:-
A Queue is a Linear data structre that follows the first-in-first-out(FIFO) principle.

Core Operations:-
add(element)/offer(element):- Insert an element at the rear.

remove()/poll():- Remove and return the Front element.

Peek()/element():- Retrieve the front element without removal.

size():- Return the number of elements.

isEmpty():- check if the queue is empty.

Usage:-
. Commonly used in Schedulling , breadth-first search and buffering.

Implementation:-
. Java provides the java.util.Queue interFace. A Common implementation is via LinkedList.
