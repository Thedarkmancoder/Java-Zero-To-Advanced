#List Sorting

Sortin Basics:-
. Sorting Arranges Elements in a Specified order (natural or custom ).
. National Order For Numbers Is Ascending, For Strings, Lexicographical.

Using Collections.sort():-
. Collections.sort(List) sorts a List in Natural Order.

Custom Sorting:-
. Provide a Comparator For Custom Order(eg. descending Order).
. Lambda expressions can be used for concise custom comparators.

Considerations:-
. Sorting an ArrayList is generally fast using merge sort.
. for linkedlist , sorting is less efficient due to sequential access.

Key Points:-
List sorting is essential for data organization java provides built in methods for both natural and custom ordering.
