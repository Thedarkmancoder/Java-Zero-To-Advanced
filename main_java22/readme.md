#Stack

Definition:-
A Stack is a Linear data Structure that follows the Last-In-First-Out(LIFO) Principle.

Core Operations:-

push(item):- Add an item to the top of the stack.
pop(item):- Remove and return the top item.
Peek():- Return the top items without removing it.
empty():- Check whether the stack is empty.
Search(item):- Return the 1-based position from the top of the stack.

Usage:-
Useful in scenarios such as expression evaluation backtracking and function call management.

Implementation:-
Java provides the java.util.Stack; class which extends Vector.
